# Школьный Помощник PWA v2

Главная начинается с расписания. Отдельная вкладка «Цели» удалена.

## Оценки
- Изначально нет ни одного предмета и оценки.
- `+` сверху добавляет предмет.
- `+` в меню предмета добавляет оценку.
- `⋮` у предмета: добавить оценку / удалить предмет.
- Для каждого предмета отдельно выбирается цель `4` или `5`.
- Под средним показывается, сколько ещё оценок выбранного значения нужно.
- Округление: 3.49 → 3, 3.50 → 4, 4.49 → 4, 4.50 → 5.

## Расписание
- Первым на Главной всегда стоит расписание.
- Фото загружается через Gemini.
- Класс берётся из Настроек и подставляется в промпт.
- После успешного распознавания новое расписание полностью заменяет старое.
- `⋮` → загрузить новое расписание или удалить текущее.

## Gemini
По умолчанию используется `gemini-3.6-flash` через Interactions API. Фото передаётся как inline base64 image. API key вводится пользователем в Настройках и хранится в localStorage, не в GitHub. Для публичного сервиса безопаснее использовать серверный proxy.

## GitHub Pages
Загрузи содержимое этой папки в репозиторий и включи GitHub Pages для `main`/root. PWA будет открываться по HTTPS.
